# AI Token-梁文锋520投资讲话精华

⚠️ **本模块材料真实性未经当事人确认，且可能含违反会议约定流出的非公开数据。所有具体数字均为「待证实」状态，不得用于对外材料。**

来源是一份标注为《梁文锋投资者交流会·录音文字稿》的材料，音频标注日期 5 月 20 日、时长约 3 小时 44 分，经 AI 自动转写整理。原稿本身声明"个别专有名词与数字可能存在识别误差，请以原录音为准"，公开网络检索不到原始音频，梁文锋与 DeepSeek 至今既未确认也未否认。文稿中主持人明确提醒与会者不要外传数字（特别点名卡量）也不要录屏对外分享，说明其中的非公开经营数据属于违反会议约定的泄露信息。

**使用纪律**：本页所有内容一律用"据传/流出材料称"的措辞表述，不得说"梁文锋说过……"，只能说"行业内流传的一份材料显示……"，且只用于内部推演。其中的算力规模、成本结构、融资情况、内部利润倍数等数字，严禁出现在任何对外材料、销售话术、投资人 BP 或公开内容中——法律与商誉风险远超其谈资价值。

## 据传的核心定价逻辑

流出材料称，DeepSeek 的 API 定价原则是设备成本十个月内回收、对应约六倍利润，V3.2 Flash 等产品均按此标准定价。若属实，这意味着上游价格结构性地变得可预测：不会因追求利润最大化而暴涨，也不会跌破成本回收线而崩塌。这对我们此前基于智谱涨价 83% 得出的"行业进入涨价周期"判断（见 [[AI Token-战略推演与终局判断]]）需要加一层限定：涨价周期主要发生在把定价交给市场博弈的厂商身上，对把定价锚定在自身成本回收周期的厂商，价格是被主动锁住的。

材料还称"价格翻倍或减半，token 消耗量区别不大"，即需求缺乏弹性——这从供给侧最强玩家的经验独立佐证了[[AI Token-商业模式与价值主张]]中"不要打价格战"的判断，也意味着我们靠折扣冲量的思路在这个市场里大概率无效，能换来量的只有新客户、新场景，不是更低单价。

材料中还有一句需要正视的表述：按十个月回本定价，能让独立部署的第三方无利可图，因为第三方做不到这个成本。这句话有两面：一方面削弱了模块 19 收录的"自建推理替代 API 采购"风险（至少在这一系模型上自建不划算）；另一方面这个定价目标本身就是要压制包括我们在内的所有中间环节的套利空间——靠价差活的中间层没有长期未来，收入必须加速从"价差"迁移到"软件费+节省分成+服务费"（呼应 [[AI Token-定价体系与单位经济模型]]）。材料称利润倍数未来可能降到三四倍、但难以再大幅下探，规划假设应是该系模型价格未来 12 个月小幅下行或持平，不宜基于"持续大幅降价"做囤货决策。

## 开源逻辑的隐含条件

材料称，开源与商业化不冲突的前提是把利润压得足够低（约六倍而非上百倍）——利润越薄，第三方即使拿到完全相同的开源模型，也难以靠自建部署赚到钱。换句话说，低毛利本身就是开源的护城河，开源不是慷慨，是以放弃暴利换取生态与安全的策略。对客户提"我们可以自己部署开源模型"时，可参考材料中提及的担忧作回应：部署得起来不等于部署得好，细节不到位效果会差、成本会更高——这正是托管与优化服务的价值位置。

## 竞争格局与技术路线（据传）

材料判断大模型竞争终局的差距只剩成本、时间、体验三项，国内基模厂商会收敛到三四家。这与我们在[[AI Token-战略推演与终局判断]]中"哑铃结构"（中低端商品化、前沿持续分化）的判断有分歧，倾向保留原判断，因为材料自身也承认在超大规模模型训练上与美国存在数量级算力差距、短期难以弥合，说明前沿仍在分化；但"国内几家之间不会有暴利"的判断可以采信。材料还提到一段关于"愿景越小越容易赢"的推演，对我们的警示是：立身之本不能是价差多少，只能是价差之外还提供了什么。

技术路线上，材料称其自研高级语言可将 CUDA 生态重写、效率损失极小，判断国产 AI 芯片生态问题不在硬件而在产能，预计一年内会被事实扭转（交叉参考 [[AI Token-国产算力卡现状与对策]]）；若属实，这意味着推理成本会进一步下移，是批发囤货业务的风险信号。AGI 技术阶梯的判断为语言模型→思维链→Agent→持续学习→自我迭代奇点→具身智能，当前处于 Agent 阶段，下一瓶颈是持续学习；并称国内现阶段最合理的做法是全力做通用 Agent、优先 Coding Agent，这与我们对[[AI Token-编程Agent]]战略重要性的判断相互印证。

## DeepSeek 的商业化姿态——对我们价值主张最强的佐证

材料称该公司将卖 API 视为做 AGI 路上的"副产品"，只需要几个人维护、没有客服、不用销售、也不做向上游应用的垂直整合。这几点与我们的价值主张几乎逐条对应：对方没有客服，我们提供技术支持与故障响应；对方不用销售，我们提供方案设计与选型咨询；对方不做垂直整合，我们提供场景落地与成本优化。如果这份材料属实，这是"复杂度税"论点能拿到的最强证据之一。同时它也提示，"厂商直销下沉"这条威胁至少对这一家厂商应当降级，但对有完整销售体系的云厂商仍然成立。

## 一句话总结（据传材料的整体含义）

若材料属实，它同时说明：上游价格是可预测的（锚定成本回收周期）；价差空间是被主动压薄的（上游明确以"让第三方无利可图"为目标）；服务空间是被完全让出来的（上游自己不做客服、销售、垂直整合）。三条合起来指向同一个结论——不能靠价差活，只能靠上游明确不做的那部分活。
