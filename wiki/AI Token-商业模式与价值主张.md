# AI Token-商业模式与价值主张

[[AI Token 业务]]知识库模块 02，解决的问题是：我们凭什么存在、凭什么赚钱、别人为什么替代不了我们。全员必修，也是投资人沟通的核心素材。

## 最尖锐的那个问题

任何懂行的客户、投资人、竞争对手都会第一时间质疑："模型厂商官网就能直接注册、直接调用、直接充值，为什么要经过你？你不就是个加价的中间商吗？"

真实的答案：我们不是在"模型和客户之间"加了一层，而是在"客户和五到十个模型厂商之间"减了九层。一家想用好当下模型生态的公司，不可能只用一家模型（DeepSeek 便宜且推理强、通义多模态好、豆包某些中文场景强、智谱 Agent 能力专业、部分场景必须用海外模型），一旦用多家就要同时承担五套 API 协议和 SDK、五个充值账户、五套限流规则、五份分散账单、五次商务谈判与发票流程、五份合规备案材料。这些成本不出现在任何价目表上，但真实消耗着客户最贵的资源——工程师时间和财务时间。我们收取的差价，本质上是客户为消除这些成本而付的钱，即所谓的**"复杂度税"**。

一个反向判断标准同样重要：如果客户只用一个模型、用量极小、不需要发票、不在乎稳定性，那他确实不该是我们的客户，硬啃这类客户既没利润也没口碑。识别"不该服务谁"和知道"该服务谁"同样重要。

## 四条业务线及其递进关系

我们同时经营四条业务线，不是并列的四个产品，而是有递进关系的结构：**代理身份换信任，聚合网关换数据，批发分销换规模，解决方案换利润。**

**渠道代理**（国内大模型官方代理）：与厂商建立正式渠道协议，以代理价拿货，为客户提供采购、开票、技术支持与售后，赚厂商的代理折扣与阶梯返利。战略作用是信任资产——官方代理身份意味着不是野生中转站，是中大型客户合规审查、法务审查的第一道筛子。风险是厂商政策变动、代理权被稀释、厂商直销抢客户，应对是不依赖单一厂商、把价值沉淀在服务层而非通道层。

**多模型聚合网关**（自有产品）：统一 API、一个账户接入所有主流模型，原生兼容 OpenAI/Anthropic/Gemini 三套协议，提供细粒度账单、缓存可见性、智能路由、故障自动切换（技术细节见 [[AI Token-供给体系与产品架构]]）。赚的是上游拿货价与对客销售价之间的价差,加上高阶功能服务费。战略作用是产品资产和数据资产——每次调用都在告诉我们市场用什么模型、哪里能优化,这是从"中间商"进化为"AI 成本管理服务商"的唯一路径。

**算力/额度批发分销**：以大额预付换取上游更深折扣，批发给下游代理商、小型服务商、有稳定用量的中型客户，赚批零价差，规模是唯一杠杆。战略作用是现金流引擎和议价筹码——批发采购量直接决定我们在上游能拿到的价格，进而决定另外三条线的竞争力。这是四条线里**风险最高**的一条：预付资金被锁定、下游账期与坏账、囤额度遇降价直接亏损，必须设置严格资金上限和降价对冲机制（详见 [[AI Token-定价体系与单位经济模型]]与 [[AI Token-合规与风险控制]]）。

**场景化解决方案**（延伸业务）：基于前三条线积累的客户理解与调用数据，提供模型选型咨询、成本优化、路由策略设计、trace 与评测基础设施、私有化部署对接。赚项目制服务费与持续优化订阅费,是毛利率最高的一条线（可达 50%–70%）,是前三条线在清洗期毛利被压缩后公司能活下去并向上走的终局业务。

这条线在 2026-07 有过一次重新定位：原本包含"场景化 Agent 开发"，但随着"企业核心智能不能外包"成为行业主张，客户不会再买"你替我建一个 Agent"。现在的定位是从"替客户建"改成"让客户自己建的东西跑得更省、更稳、更看得清"——提供脚手架和度量，客户保留领域知识与业务逻辑，毛利结构和可复制性都优于定制开发，也避开项目制交付的人力陷阱。配套的技术路径也已明确分级：可做 L0–L2（上游缓存对齐、模型路由降本 35%–45%、单租户评测集与示例库沉淀），不可做 L3–L4（用客户数据微调经济性不成立、跨客户数据混用是红线）。这条线不碰客户领域知识的定位，在合规与技术两条独立路径上都得到了验证（详见 [[AI Token-客户数据合规边界]]）。

早期（0–12 个月）以代理和聚合为主快速建立客户基础；中期（12–24 个月）用批发放大规模、压低上游成本；长期以解决方案承接利润。任何时候如果只剩批发分销还在跑，说明公司战略已经失败——纯批发是最容易被规模更大的对手碾死的形态。

### 候选的第五条线：Token 工厂

这条线目前**不成立**，列出来是为了防止被反复重新提起。它是指不再只做转售，而是自己持有推理算力、自己出 token，从"渠道"变成"供给"。不做的理由基于对硅基流动 2025 年公开财务的拆解：收入 5533 万（同比 +653%），亏损 3.45 亿，整体毛利率 −24.0%，其中公有云业务毛利率 −119.0%，月均现金消耗约 1480 万——一家有千万级注册用户、上万企业客户的头部玩家在公有云 token 上每卖一块钱倒贴两块多，我们没有理由认为自己能做得更好。但同一组数据显示本地部署/私有化交付的毛利率约 +82.6%，因此结论是有条件的：不做公有云 Token 工厂是明确红线；若要碰"供给"，只能从本地部署/私有化交付切入，且要按签约负载（而非预期客户数）分阶段推进（详见 [[AI Token-Token工厂可行性与起步路径]]）。在早期阶段，这其实是场景化解决方案线的一种交付形态，只有开始持有资产后才在会计和风险上真正成为独立的第五条线。

## 价值主张：对四类客户各说一句话

同一套能力要对不同客户翻译成不同语言：

- **AI 应用创业公司**（痛点锚点：工程效率、现金流）："你的工程师应该花时间做产品，不是维护五套模型接口和五个充值账户。一行代码切换所有模型，一张账单看清所有成本。"
- **中大型企业客户**（痛点锚点：合规、可审计、可问责，价格通常排第三第四位）："我们是官方授权渠道，合同发票备案一次性给全；子账号和部门预算管控让 IT 部门知道每一分 AI 支出花在哪；SLA 和故障补偿写进合同。"
- **中小企业与开发者**（痛点锚点：门槛和便利，是口碑扩散主要来源）："不用注册五个平台，不用最低充值门槛，按量付费，账单一目了然。"
- **下游代理商与渠道**（痛点锚点：低门槛创业、稳定分润）："我们提供白标网关、独立结算后台、分级分润，你只管卖，交付和技术我们兜底。"（详见 [[AI Token-渠道与代理商体系]]）

## 护城河：现在有什么，将来要建什么

诚实地说，0→1 阶段几乎没有护城河，这一点对内对外都要讲清楚——面对投资人虚构护城河最容易被戳穿。现在有的只是三样可被复制的东西：起步期服务密度、合规意愿、模型选型专业判断。

真正需要在 12–24 个月内建起的护城河有四层：**转换成本**（路由策略、缓存配置、成本报表、账号体系都建在我们平台上后迁移成本变高，靠产品深度实现，是最快能建起的一层）、**数据壁垒**（积累足够调用数据后能回答"这个场景用哪个模型最划算"，靠时间和规模实现）、**合规资质**（完整资质组合本身构成准入门槛，靠钱和时间实现，可以现在启动，详见 [[AI Token-合规与风险控制]]）、**渠道网络**（覆盖细分行业和区域的代理商网络一旦形成粘性很难被撬动，最慢但最稳固）。前 12 个月的正确姿势是用服务密度换客户，同时把合规资质和产品深度同步推进。

## 这门生意可能失败的四种方式

- **被上游抛弃**：厂商直接服务所有客户、取消渠道体系或收紧代理折扣。这是最致命的、我们几乎无控制力的风险，唯一缓解是不依赖单一上游、让客户粘在产品能力而非通道上。
- **被价格战杀死**：规模更大的对手把价差压到零。应对是坚决不跟进纯价格战，把竞争转移到服务和管理能力维度。
- **被合规清退**：监管收紧、资质不全，或客户用通道做违规内容生成导致连带责任。应对是 [[AI Token-合规与风险控制]] 的全套风控体系必须在扩张前就位。
- **被资金链拖垮**：批发业务固有风险——大额预付、下游账期、遇上游降价或下游坏账导致现金流断裂。应对是严格预付上限、账期管理和降价条款谈判。

对投资人讲这四条不是自曝其短，而是证明清醒——说不出自己怎么会死的创业者，投资人不会信他知道怎么活。
