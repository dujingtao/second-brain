# AI Token-定价体系与单位经济模型

[[AI Token 业务]]知识库模块 04，标注为内部机密文件（对外分发版本须删除成本与毛利数据）。解决的问题是：一笔单子到底赚多少、怎么报价不亏、什么时候该拒绝订单。使用者是销售（报价前必读）、决策层、财务。

毛利测算公式本身（收入/采购成本/毛利率的具体计算方式、贡献毛利公式、客户健康度分级、报价审批权限表）与管理台"毛利测算器"的实现完全一致，机制细节见 [[AI Token-站点部署与访问控制]]，此处不再重复，只梳理背后的成本结构、定价策略和风控逻辑。

## 成本结构拆解

一笔 token 收入背后的成本由五部分构成，销售心里必须有这张成本表，否则"感觉还有得赚"的单子实际上是亏的：

- **直接采购成本**：上游实际拿货价，占比最大。以行业公开加成水位推算，若对客按官方价 88 折销售、自己按 78 折拿货，采购成本约占收入 89%，毛利率约 11%——这就是纯转售业务的真实水位，十个点出头，没有想象空间。
- **技术与带宽成本**：网关服务器、流量、日志存储（6 个月留存是硬要求，存储成本不小）、监控告警系统，按收入 2%–4% 估算。
- **服务成本**：最容易被低估的一项。技术对接、故障响应、账单答疑、优化建议这些人力投入,在小客户身上摊薄后可能超过毛利本身——月消费 2000 元、每周找技术支持三次的客户是纯亏损客户。
- **资金成本**：批发业务特有,预付上游资金被锁定加上下游账期,中间资金占用有实际的机会成本和融资成本。
- **风险成本**：坏账准备、SLA 赔付准备、上游降价导致的存货贬值准备,起步期建议按收入 2%–3% 计提。

把五项加总，纯转售业务的净利率在起步期大概率是负的或接近零。这不是失败，而是这门生意的常态——转售业务的作用是获客和获取数据，利润必须来自增值服务和规模化后的上游折扣提升。这个认知如果不在全员脑子里，销售就会为了冲量签下一堆亏损订单。

计算毛利时必须按输入、输出、缓存三类分别计算，不能用总 token 数乘平均价——因为输出价通常是输入价的 3–4 倍，不同客户的输入输出比差异巨大（长文档摘要客户可能是 50:1，内容生成客户可能是 1:5），用平均价估算误差可达两三倍。"主动退出客户"必须成为一个被允许、甚至被鼓励的动作——起步期公司最常见的错误是把所有客户都当宝贝，结果被少数几个高服务强度的低毛利客户耗死。

## 定价策略：三层结构

定价分三层。**引流层**对标官方价 85%–90%，用于通用低价模型和新客户首单，毛利极薄甚至为零，作用是获客和建立价格认知，不考核毛利、只考核转化。**主力层**对标官方价 90%–95%，用于主流中档模型，是毛利的主要来源，也是绝大多数订单应落在的区间。**价值层**不与官方价直接对标，而是打包定价——网关服务 + SLA 保障 + 管控功能 + 优化服务,按"平台服务费 + token 用量费"组合收取,毛利率可做到 30%–60%,是真正要引导客户去的方向。

量价阶梯设计要与从上游拿到的阶梯折扣结构对齐（上游在某个采购量给我们提折扣，我们对客的阶梯拐点就该设在能推动我们跨过那个量的位置）。三条纪律：折扣只随实际用量兑现，不预支（承诺量不等于实际量，预支折扣是常见亏损来源）；阶梯以季度而非月度考核；最高阶梯折扣必须给公司留不低于 8% 的毛利底线，触及底线需上报审批。低于 8% 毛利率的订单不是不能签，而是必须有明确战略理由（标杆客户、行业突破口、渠道网络），理由要写进审批记录，季度复盘验证是否兑现。

## 批发/囤货业务的专项风控

这是四条业务线（参见 [[AI Token-商业模式与价值主张]]）里唯一可能造成灾难性损失的一条，规则必须比其他业务严格得多。

**降价风险是首要风险**：上游模型价格若在下行通道，今天以 78 折囤的额度，若三个月后官方直接降价 30%，这批额度的市场价值直接跌破成本。所有大额预付必须在合同中争取降价保护条款（官方降价按新价折算或补差），拿不到这一条的预付必须大幅压缩规模，并把额度周转周期控制在 60 天以内。

**流动性风险是第二风险**：预付款是沉淀资金，下游账期是应收账款，两头挤压最容易断裂。三条硬线：预付资金不超过可用现金的规定上限（起步期建议 30%）；单个下游客户应收账款不超过总应收的 25%；账期超过约定天数自动停止供货。

囤货规模应基于过去 90 天实际日均消耗推算，覆盖期不超过 60 天：建议预付额度 = 近90天日均消耗 × 60天 × (1 + 增长系数)，增长系数在 0.2–0.5 之间视增长确定性而定。绝不基于"预期签约量"囤货——预期会落空，额度不会自己变回现金。

## 单位经济模型示例给出的核心结论

模块中给出的示例数据（月消费 5 万元、中档模型组合、输入输出比约 3:1 的典型客户）标注为"结构示例、非真实业绩数据"，实际按主力层定价测算下来贡献毛利率只有约 3%，属于健康度分级中的"临界"档。这个数字本身不是要点，要点是它揭示的三件事：纯转售单靠价差养不活公司；服务成本的控制比价差的争取更重要；必须向增值服务要利润——同一客户如果同时购买成本优化服务（按节省额分成），贡献毛利率可以直接翻倍还多。

给决策层的核心结论：**这门生意的利润杠杆不在采购端，在服务端。** 把 80% 的精力放在跟上游磨 2 个点的折扣上，不如把精力放在让更多客户购买增值服务上。

## 财务监控指标

建议按月跟踪四类指标：规模类（月度 token 消耗量、月度收入、月度采购额、活跃客户数）、效率类（综合毛利率、贡献毛利率、ARPU、销售人均产出）、质量类（客户留存率、净收入留存率 NRR、增值服务渗透率，目标渗透率 30%）、风险类（应收账款周转天数、预付款占比、单一上游采购集中度、单一客户收入集中度、坏账率）。

其中 **NRR 是所有指标中最重要的一个**，它同时反映客户满意度、扩量能力和定价合理性；健康值应大于 110%，持续低于 100% 意味着老客户在流失或缩量，此时再多新客户也只是在填漏斗的洞。
