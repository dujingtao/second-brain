# AI Token-Token工厂可行性与起步路径

[[AI Token 业务]]知识库模块 25，数据采集于 2026-07-27。解决的问题是：要不要自建推理产能（"Token 工厂"）？如果要，从几个客户、多大负载开始？⚠️ 结论是"现阶段不做公有云 Token 工厂"。

## Token 工厂是什么，和现在的生意有什么本质区别

"Token 工厂"指自己持有或租用算力、部署模型、把 token 作为商品生产并对外销售的服务商——不做模型也不做应用，把异构算力、多模型和企业调用需求封装成可交付、可计量、可收费的服务。与现有转售/聚合模式相比，这是从贸易变成制造：固定成本从接近零变成极高（卡、机房、电力、运维），边际成本从等于上游采购价变成主要是电，毛利结构从薄但稳定变成利用率决定生死，失败方式从慢慢被挤掉变成可能一次性拖垮公司。这不是业务延伸，是换一门生意做，需要的资本结构、技术能力、组织形态完全不同。

## 看似成立的逻辑，以及它漏掉的东西

[[AI Token-客户需求测算与选型方法论]] 给出过一个关键数字：自建比调 API 便宜的利用率临界点约 52%。单个企业客户的 GPU 利用率只有 30%–50%（业务有波峰波谷），而 API 厂商聚合成千上万客户后利用率能做到 90% 以上。由此很容易推出"我们有足够多客户就能把利用率做到 90%、该自己造 token"的结论。这个逻辑本身没错，但漏掉了三件事：行业当前的实际毛利水平、价格战的进行时状态、以及自身的能力缺口。

## 行业标杆的真实处境：一个残酷的对照

硅基流动是中国最成功的独立 Token 工厂（中国第四大词元供应平台、独立平台第一、市场份额 1.5%、服务 13000+ 企业客户）。其招股书数据显示：2025 年收入 5533.0 万元（同比 +653.2%），但整体毛利率为 −24.0%，年内亏损 3.45 亿元（增 4.2 倍），月均现金消耗率 1480 万元。最关键的数字是**公有云服务毛利率 −119.0%**——每收 1 元钱，成本是 2.19 元，收入越多亏得越多。这不是"还没到规模效应"，而是在当前价格水平下公有云 token 池的单位经济模型本身是负的。这直接回答了上一节的逻辑漏洞：利用率不是唯一变量，售价也是，当售价被价格战压到成本线以下时，再高的利用率也救不回来。

## 反推出的核心结论：本地部署才是能赚钱的那一半

用硅基流动披露的整体收入、整体毛利率、公有云收入及毛利率四个数字，可以反推出未单独披露的本地部署业务毛利率：整体毛利 = 5533.0 × (−24.0%) ≈ −1327.9 万元；公有云毛利 = 2926.1 × (−119.0%) ≈ −3482.1 万元；本地部署毛利 = −1327.9 − (−3482.1) ≈ +2154.1 万元；本地部署收入 = 5533.0 − 2926.1 = 2606.9 万元 → **本地部署毛利率约 +82.6%**（此为基于公开数据的推算，非该公司直接披露，方向性结论可靠，具体数值仅供参考）。

同一家公司同一年，公有云 token 池毛利率 −119%、本地部署毛利率 +83%，反差揭示：公有云 token 是标准品、在打价格战、毛利为负；本地部署是解决方案、有交付门槛、毛利率超过 80%。如果要碰"生产"这件事，该做的是本地部署与私有化交付，不是公有云 token 池。这与 [[AI Token-战略推演与终局判断]]（标准品毛利被系统性挤压）、[[AI Token-梁文锋520投资讲话精华]]（上游明确以"让独立部署第三方无利可图"为定价目标）的判断完全一致，是第三次独立印证。

## 修正此前的判断：价格战仍在进行时，市场是分化而非单向涨价

此前根据智谱 API 定价提升 83% 的数据判断"2026 年行业从价格战转入价值战、进入涨价周期"，⚠️ 这个判断过于绝对，需要修正。同期数据显示自 2023 年起 API 累计降价十余次，DeepSeek V4-Pro 降价 75% 至 6 元/百万 Token，小米、腾讯跟进降幅达 97.5%–99%。准确的表述是市场出现分化：走价值战的（如智谱）提价、靠能力与场景溢价；走规模战的（如 DeepSeek 系及跟进者）继续降价、靠成本领先与体量，两条路线同时存在且都理性。做公有云 Token 工厂就是选择进入规模战那一侧，对手是有自有芯片、自有电力、极致工程优化能力的巨头。

此外还有两条长期威胁：端侧分流（行业预测未来 30%–50% 的推理需求将在端侧完成，直接收窄云端 Token 工厂的增长天花板）；以及"效率提升速度跟不上价格下降速度"的三重挤压（大厂下场、头部客户自建集群、端侧 AI 普及）。行业融资很热（硅基流动超 20 亿元 B 轮、无问芯穹累计超 22 亿元），但融资额与盈利能力是两回事，部分投资人已判断该赛道存在"一定泡沫迹象"。

## 结论与可行的切口

**现阶段的明确结论：不做公有云 Token 工厂。** 理由：行业标杆公有云毛利率 −119%、规模越大亏越多；价格战仍在进行；上游以"让第三方无利可图"为定价目标；自身没有规模、没有资本、没有推理优化的技术积累；端侧分流长期收窄天花板——这条路上没有任何一项能赢的要素。

**真正可行的切口是本地部署与私有化交付**，依据是本地部署毛利率约 +83% 这组推算数字。它不是标准品：有交付门槛（部署、调优、验收、运维）、有场景绑定（客户数据、流程、合规要求），客户买的不是 token 而是一套跑得起来的系统。这与 [[AI Token-国产算力卡现状与对策]] 识别的信创合规通道机会（政务、金融、国企要国产化又建不起来）本质衔接，也与场景化解决方案线天然衔接——不需要新开业务线，而是把已有解决方案线往"交付能力"方向做深。

三条不该碰的红线：不为压低采购成本而自建（上游定价目标就是让这件事不划算）；不先买产能再找客户（重资产业务最经典的死法）；不进入公有云 token 的价格战（那是有自有芯片和电力的玩家的战场）。

## 分阶段起步路径

判断"多少客户的时候怎么做"的关键指标不是客户数，而是**可预测的基础负载**——三个负载稳定的客户比一百个用量飘忽的客户更适合支撑自建。

- **阶段 0·当前**：纯转售、零固定成本，维持现状并积累判断下一阶段的数据（哪些客户负载稳定可预测、波峰波谷形态、私有化需求真实频次）。退出条件：出现两个及以上愿意为私有化/独占实例付费的客户，且需求可验证。
- **阶段 1·试水**：触发条件是 1–2 个已签约或付定金的确定私有化交付订单，做法是租用算力、不采购，目标是验证部署调优能力、交付周期与人力成本真实数字、客户愿为托管服务付多少溢价。必须先租不买，因为在能力未验证前投入重资产不可接受，租用买的是"随时能退出"的期权。
- **阶段 2·小规模自建**：三条触发条件须同时满足——稳定基础负载能撑住 60% 以上利用率（留出高于 52% 盈亏平衡点的安全边际）；负载来自签约客户合同承诺而非销售预测；阶段 1 已验证交付能力且毛利为正。测算方法沿用 [[AI Token-客户需求测算与选型方法论]] 的盈亏平衡公式，把 [[AI Token-国产算力卡现状与对策]] 记录的"200 万元/台"作为硬件锚，月固定成本须包含硬件折旧、电力、带宽、机房、运维人力、模型迭代跟进、峰值冗余、资金占用全部八项（运维人力最常被漏掉）。
- **阶段 3·规模化**：只在阶段 2 连续两个季度贡献毛利为正、利用率稳定在 70% 以上、且有排队等待的私有化需求后才考虑，在此之前不讨论规模化。

## 观察指标：什么会改变这个结论

公有云 token 行业毛利率转正（当前标杆 −119%）；硬件成本转向（国产先进制程良率是否突破 60%、8 卡服务器标价是否掉头，见 [[AI Token-国产算力卡现状与对策]]）；自身私有化交付订单频次（一个季度内出现三个以上因产能不足而错失的私有化需求，说明市场在推着往前走）。本模块也触发了对既有认知的修正：基本认知第一条从"2026 进入涨价周期"改为"市场分化：部分厂商涨价走价值战、部分继续降价走规模战"；业务线判断新增 Token 工厂作为候选第五条线，结论是现阶段不做公有云、可从本地部署切入。
