# AI Token-行业与Token经济

[[AI Token 业务]]知识库模块 01，解决的问题是：这个市场有多大、结构是什么、往哪走、钱在哪个环节。使用场景是投资人沟通、决策层判断、新员工建立行业常识。

## Token 是什么、为什么按它收费

Token 是大模型处理文本的最小计费单位（中文大致一字对应 0.6–1 个 token，英文一词约 1.3 个 token）。厂商对输入、输出分别计价，输出价通常是输入价的 2–4 倍，因为输出是自回归逐个生成，算力消耗远高于并行编码的输入。

按 token 计费意味着收入天然与客户使用深度绑定——不存在传统软件"卖出去就到头"的天花板；同时也意味着客户成本浮动、不可预测，这正是提供成本管理价值的空间所在。一个值得对销售反复强调的细节是**缓存命中价格**：多数厂商对重复的前缀输入提供大幅折扣（常见为原价的 10%–25%）。系统提示词很长、每次调用重复传输却不用缓存的客户，成本可能是用缓存客户的三到四倍——这是最容易做出的"立刻见效"的价值证明。

## 市场供给格局（2026 年 7 月）

国内主流模型的价格带已形成清晰的三层结构：0.3–0.8 元/百万 token 的走量层（如文心一言 Speed、通义千问 Turbo）、2–5 元的主力层（如 DeepSeek V4）、5–15 元的旗舰层（如通义千问 Max、智谱 GLM-Plus）。免费额度已成为标配获客手段（如智谱 GLM-Flash 每日 100 万 token 免费），意味着最底层通用问答场景基本无转售利润，利润必须来自中高层。同时同价位模型能力差异正在拉大，DeepSeek V4 以走量层价格提供接近旗舰的能力，对整个价格体系构成持续的向下压力。

聚合平台市场的参与者分三类：云厂商自营 MaaS 平台（阿里云百炼、腾讯云、火山方舟）资质齐全、SLA 有保障，但生态封闭、对小客户颗粒度粗；独立聚合服务商（硅基流动、OpenRouter 等）模型全、切换快，但稳定性和合规性参差不齐；开源自建网关（如 New API 一类项目）零授权成本，但缺乏企业级保活机制和合规能力。行业普遍采用差价加成制而非分成制——以官方价折扣拿货，按接近官方价对外销售赚中间价差，常见对客报价在官方价 8–9 折，公开毛利率水位大致 10%–25%，纯转售模式利润空间明确有限。

现存平台普遍存在四类通病，也是产品设计方向与销售攻击点：**稳定性缺失**（无企业级保活、无 SLA、无故障补偿）、**协议转换损耗**（不能原生支持 OpenAI/Anthropic/Gemini 三套协议，需中间件转译，引入延迟并可能丢失字段）、**缓存不可见**（账单无法区分缓存命中调用，客户无从优化成本）、**企业管控缺失**（子账号、部门审计、预算告警、正式发票，绝大多数中转站都提供不了）。

## 需求侧：Token 消耗的结构性增长

本模块最重要的认知是：无论单价崩塌还是回升，企业 AI 支出都在持续膨胀。

需要注意的是，模块原文对价格方向的判断在 2026-07 有过一次修正：早期观察到的是"降价但支出上升"的悖论；2026-07 的更新显示价格方向已经反转——行业从价格战转入价值战，出现系统性涨价（智谱 API 定价 +83%，同期消耗 +400%），驱动因素是 Agent 消耗指数级增长、存储芯片进入卖方市场与能源成本高企、以及"不能靠补贴降价"的行业共识。"降价"的描述只适用于 2023–2025 年，而"总支出持续膨胀"这一结论在涨价周期下只会更成立（完整推演见 [[AI Token-战略推演与终局判断]]）。

一条反直觉事实：低价模型往往更贵。能力弱的模型需要更多轮次、更长思考链、更多重试才能完成同一任务，总消耗反而高于直接用贵模型一次做对。客户真正付的是单位任务成本，不是单价。

支出膨胀的根本原因是工作负载形态的迁移：早期"一问一答"一次交互消耗几百到几千 token；现在主流的 Agent 形态需要多轮思考、调用工具、读取长上下文、自我校验，一次任务可能触发几十次模型调用，消耗放大十倍到百倍。两个公开案例很有说服力：Uber 为 5000 名工程师开放 AI 编程工具，四个月烧光全年预算；米哈游一位工程师做多 Agent 协作测试，13 小时产生 200 万元账单。这类案例在销售场景中的作用不是吓唬客户，而是引出一个问题——"你们现在有没有办法在账单出来之前，就知道某个功能上线会烧掉多少钱？"

需求端的量级参照：金山办公 AI 月活突破 8013 万（同比 +307%），日均调用量超 2000 亿次。这类超大客户不是我们的目标客户（他们会直接和厂商签战略协议），但证明了中间层长尾市场同样在被这股浪潮抬升。

厂商定价策略已明确分层：轻量通用模型维持低价甚至免费用于获客，编程、Agent、多模态等高价值能力按旗舰档位计费（智谱 GLM-5.1 对标编程与 Agent 场景，定价约为轻量版 GLM-4.7 的三倍）。这个分层对我们是利好——低价层没有利润，本来也不该竞争；高价层客户对价格不敏感、对能力和稳定性敏感，正是能提供增值服务的地方。销售策略应明确：用低价层做引流和试用,用高价层做利润。

## 上游侧：算力约束与价格底线

模型价格下限受制于算力成本。HBM 与高端 GPU 的供给缺口在 2026 年收窄至约 27%，供给紧张仍存在但已在缓解——一是上游降价空间仍存在但会放缓，无限降价的预期不成立；二是在算力仍稀缺的窗口期，能稳定拿到额度本身就是一种资源，这正是"算力/额度批发分销"业务线的立足点（参见 [[AI Token-商业模式与价值主张]]）。对决策层的判断建议是：不要押注"价格会一直降、靠差价永远有钱赚"，要押注"用量会一直涨、复杂度会一直升"——前者是别人的让利，后者是市场的规律。

## 市场演进的三个阶段

当前阶段（2026）是**混战期**：参与者众多、标准不一、合规趋严刚开始咬合，这是新进入者的窗口期。下一阶段（12–24 个月）是**清洗期**：合规要求落地会淘汰大量野生中转站，头部聚合平台规模效应显现。终局阶段是**分化期**：市场分化为超大规模基础设施型聚合商（拼成本和稳定性）与垂直场景解决方案商（拼行业理解和交付能力）两端，中间地带消失。

这个判断直接决定战略：必须在清洗期到来之前，完成从"卖 token"到"卖 AI 成本管理与场景交付"的能力积累，转售业务的作用是养活公司、获取客户和数据，而不是终点。

需要注意的是，关于清洗期"主要杀伤机制"的判断也在 2026-07 做过修正：原判断认为是"价差被压缩到个位数"，但在涨价周期下，更现实的机制是厂商向应用层上行导致的**脱媒**——上游越是自建开发者生态与应用入口，越有动力直接服务应用开发者，中间渠道的空间是被从上方压缩，而不是从价格方向压垮。这不改变"必须尽快积累场景交付能力"的结论，但改变了该防守的方向（详见 [[AI Token-战略推演与终局判断]]第五节）。
