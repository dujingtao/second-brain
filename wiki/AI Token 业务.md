# AI Token 业务（SpaceTiD）

上海火棘果数字科技有限公司（SpaceTiD）的内部业务：**国内大模型渠道代理 + 多模型聚合网关 + 算力额度批发分销**。这份内部知识库（企业知识库 v2.8，共 28 个模块，首版 2026-07-27，最近更新 2026-08-12）同时服务四类人——新销售、决策层、投资人、以及未来要吃下整份知识库的业务智能体。每条论断都要求同时给出成立理由和失效边界，涉及价格、成本、毛利的判断会随时间修正，知识库本身记录了完整的修正留痕。

这是一个索引页，具体内容分散在下面的子页面中（对应知识库的模块编号）。

## 贯穿全局的六条基本认知

1. **不管单价怎么走，Token 总支出一直在涨。**（2026年行业已从价格战转入"市场分化"——部分厂商如智谱涨价走价值战，部分如 DeepSeek 系继续降价走规模战；无论方向如何，客户侧总支出因 Agent 型工作负载而持续膨胀。反直觉推论：低价模型往往更贵，因为弱模型需要更多轮次才能完成同一任务。）
2. **赚的不是差价，是"复杂度税"。** 把客户对接五套模型协议、账单、限流、合规材料的麻烦收敛成一套，价值在于省下的工程/财务/合规时间。
3. **0→1 阶段打确定性战，不打价格战。** 拿不到最低上游折扣就打不起价格战；但稳定性、可观测性、合规票据的价值在客户被官方限流一次后会瞬间放大。
4. **客户结构决定命运，四条腿走路，单一客户类型占比不超过 40%。**
5. **合规不是成本，是准入门槛和竞争壁垒。** 2026 年起面向公众的 API 转售应用需公示模型名称、网信办备案号、留存 6 个月以上调用日志。
6. **终局不是卖 token，是卖"AI 成本管理能力"。** 转售毛利会持续压缩，真正能沉淀的资产是客户调用数据、成本优化模型、选型经验、路由策略；转售是入口，管理是终局。补充推论：正因为客户切换成本极低，公司自己也随时可能被绕过（没有模型能力、没有品牌、没有沉没成本），必须靠能力锁定而非技术锁定。

## ⚠️ 需要重点关注的合规风险

**阿里、腾讯、智谱的服务协议均明确禁止未经书面许可的转售**（智谱点名"聚合转发"，腾讯点名"API Token"）。官方渠道/经销书面授权不是可选项，而是渠道代理与批发分销两条业务线合法存在的前提，签约与商务谈判前必须先确认。详见 [[AI Token-合规与风险控制]]。
