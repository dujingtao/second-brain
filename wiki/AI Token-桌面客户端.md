# AI Token-桌面客户端

[[AI Token 业务]]知识库模块 15，覆盖 Cherry Studio、ChatBox、LobeChat、Open WebUI 四款桌面/自部署对话客户端。这一层的共同特征是：单客户用量小、笔数多、口碑扩散快，服务必须做到零人力——用销售去跟单是亏本的（一个 Cherry Studio 个人用户月消费几十到几百元，即使按 [[AI Token-定价体系与单位经济模型]] 测算的 15% 毛利率，一单毛利也就几十块，销售打一通电话就把这笔单子做亏了）。

正确打法是极致自助化 + 内容驱动获客 + 文档解决一切。但这一层仍值得认真研究，理由有三：它是口碑扩散源（开发者和技术爱好者会写教程、发社区帖）；它是企业单的前哨（员工先在自己电脑上用顺手，半年后公司上 AI 项目时会想起来）；它是产品的免费压力测试场（这批用户最先发现文档错误、模型列表未同步）。

## Cherry Studio

定位"专业级多引擎 AI 桌面助手"，开源协议 AGPL-3.0。与其他客户端的最大差异是深度：原生内置向量数据库，能做知识库问答、图像生成、Agent 工作流、MCP 支持，覆盖 Windows/macOS/Linux 三端，不做移动端。

接入网关走 OpenAI 兼容协议（设置 → 模型服务 → 添加供应商），配置体验在同类产品中最省心。token 消耗特征上，知识库问答是消耗大头且输入输出比极度失衡——典型场景输入 20,000 token（检索片段+系统提示词）、输出仅 500 token，比例约 40:1。这既意味着按平均单价估算成本会严重失真，也意味着缓存优化空间极大，是做"首月成本优化报告"最容易出成绩的客户类型之一。

典型客户是知识工作者、研究人员、独立顾问。销售切入点是模型选型建议和缓存教育（例如一篇《Cherry Studio 知识库省钱指南》）。需注意 AGPL-3.0 协议对企业客户"基于 Cherry Studio 改内部版本"的诉求有开源义务约束，应提示但不代做法律判断。

## ChatBox

强调"轻量、跨平台"，同为 AGPL-3.0 协议，平台覆盖最广（Windows/macOS/Linux/Android/iOS/Web）。相比 Cherry Studio 是"随身工具"而非"工作站"，文件读取能力基础级，没有原生向量库。

接入路径是设置里的自定义/OpenAI API 模式，天然支持自建 API 代理。消耗量在这一层里偏低（月消耗几十万到几百万 token），但因为移动端存在，使用频次可能更高。客户画像技术门槛最低，文档必须做到"手把手"级别。这一层主要靠自助转化，销售不介入；值得投入的是移动端接入教程这类差异化搜索内容。

## LobeChat

开源现代化对话框架，特点是既可本地部署也可一键云端部署（如 Vercel）。介于"个人客户端"和"团队自部署平台"之间——个人用户走自助路线，但小团队共享实例的用量会跳一个数量级，具备"企业客户雏形"。

销售应具备识别能力：客户一旦提到"我们部署了一个 LobeChat 给团队用"，很快就会遇到用量归属和成本分摊问题，这正是子账号与部门归集功能（见 [[AI Token-供给体系与产品架构]] 管控层）的切入口。接入配置核心是 OPENAI_PROXY_URL/OPENAI_API_KEY 环境变量或界面自定义地址。

## Open WebUI

本模块里企业销售价值最高的一款。最初围绕 Ollama 本地模型生态发展，后扩展为通用 AI 对话前端，天然适配"模型部署在内网"的架构，是数据不出域方案的常见前端选择。

它的核心价值场景是混合架构：企业已经在内网用 Ollama/vLLM 部署了开源模型，但发现能力不够，需要在复杂任务上调用商业模型。Open WebUI 支持同时配置多个 OpenAI 兼容连接（本地一条、我们一条），用户可在界面按需切换或按场景路由——这正是多模型路由能力（见 [[AI Token-供给体系与产品架构]] 路由层）的完美用例。销售话术是"补能力短板"而非"替换本地模型"，避免暗示客户已有投入无价值而引发抵触。

典型客户是有数据合规要求的中大型企业、政务国企信息化部门、私有化交付的系统集成商，决策链完整（见 [[AI Token-客户分层与场景库]]），销售周期 4–12 周，单客户价值高、粘性强。必须配套资质、合同、SLA、备案文件、日志留存说明（见 [[AI Token-合规与风险控制]]）。若客户要求"数据完全不出内网"，标准方案满足不了，需要走私有化部署网关组件方案（见 [[AI Token-供给体系与产品架构]]）；销售应先问清楚"不能出去"具体指什么，多数时候客户表述比实际要求严格。

## 横向对比与统一策略

四款客户端的资源分配原则：Open WebUI 值得销售介入，LobeChat 团队实例值得识别跟进，Cherry Studio 和 ChatBox 一律自助。统一要做的三件事：把每个客户端的接入文档做到最好（覆盖桌面/移动端，把 401/404/模型不存在三个高频报错写进去，见 [[AI Token-客户端技术知识库总纲]]）；做面向搜索的内容营销；建立"用量跃迁"自动识别机制——一个自助客户月消耗连续翻倍或从个人量级跳到团队量级，是从长尾客户升级为企业客户的信号，值得销售介入一次。
