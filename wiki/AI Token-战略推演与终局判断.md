# AI Token-战略推演与终局判断

[[AI Token 业务]]知识库模块 18，解决的问题是"三年后这个行业长什么样，我们该往哪站"。使用者是决策层、投资人沟通素材、以及需要理解行业走向的销售。本模块含对自身业务的负面推演，对外分发需谨慎删减相关章节（原文标注为第四、五节）。

## 待检验的核心论点

论点骨架：大模型不是一门好生意，像当年的公链——无数条链争夺同一批应用和开发者，而对开发者来说更换 AI 模型太容易（只需换一个 URL 和一个 Key）。假设三年后模型能力趋同，价格就是唯一关键因素，这会是一场无尽的烧钱游戏直到对手倒下，比公链更差（LLM 是 serverless 的，用完就走，什么都留不下）。如果价格卷到像电力一样，谁控制应用和入口谁就是老大——关键不是 Chat UI 类应用（用户能选模型），而是嵌入式 Agent（如 Telegram 的长内容优化、Gmail 的 AI 搜索，用户感知不到也无法选择模型，完全由应用方决定）。结论：模型厂商现在就该构建开发者生态和应用层制造粘性，国内厂商还停留在卷模型层次，未来可能"有模型没人用"；最快明年就是 AI 应用开发者的好日子。

## 站得住的部分

切换成本在 API 层面确实极低——这一点被 [[AI Token-编程Agent]]、[[AI Token-客户端技术知识库总纲]] 里的接入配置速查表直接证实（改个环境变量、开个 Override Base URL 开关）。这也是 SpaceTiD 整个业务存在的前提：如果切换很难，客户会被锁在官方通道里，我们连进场机会都没有——我们是这条规律最直接的受益者，也将是最直接的受害者。

价值向掌握需求的一端转移是被反复验证的产业规律（PC 时代的 Intel/微软、移动时代的应用商店、云时代的 SaaS 都是同一剧本）。"嵌入式 Agent"这个切分是全文最有价值的判断：嵌入式场景的模型采购是纯粹的 B2B 理性采购，没有品牌溢价、没有用户偏好保护，这对模型厂商是坏消息，对我们是好消息——理性采购正是我们能赢的战场。

"国内厂商应做应用层"这个判断方向对，但时点判断已滞后：国内头部厂商早已从单一模型供应转向"模型+数据+服务+生态"，MaaS 占 B 端收入超过 50%，私有化部署成为金融医疗等行业主流，这对我们反而是坏消息（见下文"真正的风险"一节）。

## 站不住或被高估的部分

### 价格判断：市场分化，不是单向涨价（⚠️ 已修正）

这是整条论证链上最关键、也是被现实证伪得最直接的一环，且本模块自身经历过一次修正：最初的表述是"2026 年反而在涨"、断言进入涨价周期；这个表述过于绝对，现已修正为**"市场分化"**——这是当前/最终结论，此前"涨价周期"的提法不再成立。

修正前的观察确有依据：头部厂商中相当一部分从价格战转向价值战开始涨价（智谱 API 定价提升 83%，同期 token 消耗量增长 400%，涨价没有抑制需求），原因包括 Agent 时代 token 消耗指数级增长、存储芯片进入卖方市场、"不赚钱产品直接被砍"的行业共识（如 Sora 因单分钟视频生成成本 30–50 美元被放弃）。反直觉事实：低价模型往往更贵，因为能力弱的模型需要更多轮次、更长思考链、更多重试才能完成同一任务，"单价"和"单位任务成本"是两回事，客户真正付的是后者。

但同样扎实的反向证据是：自 2023 年起国内 API 累计降价十余次，部分模型累计降幅超 90%；DeepSeek V4-Pro 降价 75% 至 6 元/百万 Token，小米、腾讯跟进降幅达 97.5%–99%。这两组数据描述的是同一市场的两条分岔路线——**价值战**（智谱等，涨价换毛利，赌高价值任务需求不敏感）和**规模战**（DeepSeek 系及跟进者，继续降价换体量，赌自身成本结构能撑住）。所以正确表述是"市场分化"，而不是"涨价周期"。

这一修正带来两处限定：第一，"价格战不是主要威胁"这一判断需要降级——价格战没有全面到来是对的，但在规模战那一侧仍在真实发生，准确说法是价格战不是全行业威胁，但如果客户结构集中在对单价敏感的长尾，它就是直接威胁。第二，"囤货批发在涨价周期里有机会"这条推论不再成立——方向既然不可单向预测，囤货就同时暴露在"拿不到量"和"买贵了"两个方向的风险上，[[AI Token-定价体系与单位经济模型]] 的资金上限与周转纪律必须严格执行，不得因"看好涨价"而放宽。**统一纪律：上游价格方向已不可单向预测，任何依赖价格方向的策略（囤货、锁价、长约）都必须做双向压力测试——涨 50% 和跌 50% 两种情形下都不能致命，才可以做。**

不过原判断的核心（价格不会归零、有物理硬底、"电力化"前提不成立）依然成立，被修正的只是"方向"这一层：推理有真实的 GPU 秒和电力消耗，边际成本不趋近于零，终局不会是"人人免费"，而是只有成本结构最优（自有芯片、自有电力、极致工程优化）的少数玩家能持续供给——这比原论点对小模型厂商更悲观，但不是"无尽烧钱"，而是"资本密集度筛选"，是有终点的。

### 换个 URL 就能切换：API 层面成立，系统层面不成立

改配置只要三十秒，但改完得到的是一个能跑的系统，不是等价的系统。真实切换成本藏在验证环节：提示词按特定模型调优过要重调、评测集要重跑、function calling 行为差异要重新验证、输出格式稳定性要重新压测、缓存策略失效要重建、微调模型无法迁移、长任务失败模式要重新摸。这是模块 02（[[AI Token-商业模式与价值主张]]）讲的"复杂度税"的双向性——既是我们的收入来源，也是客户流失的阻力。

后续得到了 Harness 工程的实证支撑：几乎所有编程 Agent 公司都自研 harness，性能差异不完全来自模型本身，而来自对模型在 harness 中工作方式的理解——提示词调优、评测集、trace 分析、上下文压缩、子 Agent 协调都是围绕特定模型行为积累的资产，换模型意味着这套资产要重建一遍（详见 [[AI Token-外部观点收录与研判]]）。经验上，声称"随时能切"的团队绝大多数并不真的切——能力不等于意愿不等于行动。

### 公链类比在两点上断裂

一是边际成本：出块近乎零边际成本，推理有沉重边际成本，两者价格战终局形态完全不同。二是沉淀资产：LLM 对单次调用是 serverless 的，但对关系不是——调用数据与评测资产、缓存与上下文、微调权重、企业侧采购审批记录、以及国内尤其重要的合规资产（备案关系、等保测评、审计留痕，见 [[AI Token-合规与风险控制]]）都在沉淀。国内合规审批本身就是一道换不动的墙——一家银行花三个月过完供应商准入，不会因为另一家便宜 5% 就重来一遍。

### 能力趋同是假设，且只在中段成立

头部五家（字节、阿里、DeepSeek、百度、智谱）在知识性、推理、长文本等基础能力上确实已拉平，但差异化转移到了多模态和 Agent 能力，评价标准也从"能跑多高"转向"能干多久"（长程任务稳定性），这正是最难趋同的维度。更可能的形态是哑铃结构：中低端彻底商品化，前沿持续分化。

### 结论自相矛盾

论点说"最快明年是应用开发者的好日子"，但按其自身逻辑，如果价值归于入口，而入口被 Telegram、Google、微信、钉钉、飞书以及 AI PC/AI 手机硬件厂商这类既有分发能力的巨头把持，独立应用开发者就是被上下夹击的一层：上面是商品化的模型，下面是掌握分发的平台。好日子属于已握有入口的人和垂直纵深玩家，不属于通用型应用开发者——后者做出来的东西最容易被入口方原生集成掉。

## 最不舒服的推论：这套逻辑对我们的杀伤力更大

论点说模型厂商切换成本太低随时会被换掉——那么 SpaceTiD 是什么？我们是模型和客户之间的一层，客户换掉模型厂商需要改一个 URL，换掉我们同样只需要改一个 URL。用来论证"模型厂商没有护城河"的每条理由，用在我们身上都成立，而且更严重：模型厂商至少还有模型能力、自研沉没成本、品牌，我们卖的东西和上游一模一样，只是价格和服务不同，比模型厂商更接近"纯通道"，也更接近"可被无痛替换"。

[[AI Token-商业模式与价值主张]] 已诚实承认"0→1 阶段几乎没有护城河"，这个论点把其严重性放大了：在一个所有人都在丧失锁定能力的行业里，最没有锁定能力的一层最先被挤掉。[[AI Token-核心论点库与FAQ]] 里"不做锁定反而留得住客户"这条在起步期是对的策略（客户不敢进来），但必须有下半句：不做技术锁定，就必须做能力锁定——让客户走得动但不想走，靠产品深度和数据资产，不是合同条款。这是三年后我们还在不在的分水岭。

## 真正的风险不是价格战，是脱媒

真实风险机制是：模型厂商意识到自己会被商品化 → 加速向上游走，自建应用层和开发者生态 → 而它们要争取的开发者，正是我们的客户。厂商在做 MaaS（占 B 端收入超 50%）、私有化部署、行业专用模型、C 端应用入口、AI PC/AI 手机硬件入口，每一项都在缩短它们与最终客户的距离，压缩我们的存在空间。

威胁排序：第一，**厂商直销下沉**——厂商越往应用层走，越有动力直接服务应用开发者，中间渠道价值越薄。第二，**入口方直接与厂商签战略协议**——大型入口的采购量足以直接拿到最优价和定制支持，中间层没有插入空间，我们注定服务不了最大的那批客户。第三，**自建推理替代 API 采购**（开源模型+受管运行时+自建 harness 跑在企业自有基础设施上）——这条路径一旦在受监管行业成为主流，这些客户将不再向任何人采购 token，不是被绕过，是需求本身消失，风险敞口最大的恰恰是我们最看重的金融、法律、医疗类客户；缓冲在于自建有隐性成本、混合架构才是现实形态，应对方式是从"便宜的 token 供应商"重新定位为"本地模型干不了的那部分的出口+横跨本地云端的成本核算层"。第四才是价格战——而且如上所述，2026 年实际是市场分化而非单向价格战，把战略重心押在"打价格战活下来"上是押错了战场。

## 对四条业务线的重新评估

| 业务线 | 原判断 | 推演后的判断 | 变化 |
|---|---|---|---|
| 渠道代理 | 信任资产 | 中长期贬值：厂商越下沉代理身份越不值钱；短期仍是企业客户准入敲门砖 | 下降 |
| 多模型聚合网关 | 产品与数据资产 | 价值上升：能力若真趋同，按价格与场景自动路由就是纯增值，趋同越彻底路由价值越大 | 上升 |
| 算力/额度批发分销 | 现金流引擎 | 风险显著上升：囤货风险从"只怕降价"变成同时怕拿不到量和买贵，且是最纯粹的通道生意，最先被脱媒 | 明显下降 |
| 场景化解决方案 | 终局业务 | 确认为终局，且时间窗口比原判断更紧 | 不变 |

反直觉的结论：能力趋同对我们好坏参半——它摧毁转售价差（模型可互换，客户只比价，毛利被压到底），但放大路由价值（模型可互换意味着可以在客户无感的情况下把请求调度到当下最划算的模型，节省的钱可以和客户分成）。这直接指向商业模式转向：收入应从"价差"迁移到"软件费+节省分成"，前者随商品化消亡，后者随商品化增强，这是 [[AI Token-定价体系与单位经济模型]] 里"价值层定价"应被提到战略高度的原因。

## 无悔动作与情景下注

三年期预测历史命中率都很低，正确姿态不是赌一个终局，而是分清哪些动作在所有情景下都对。

**无悔动作（立即执行，不依赖任何终局假设）**：深度嵌入客户技术栈——成为 Dify、FastGPT、Cline 等项目文档里的默认/推荐 provider，是少数还能积累的分发资产（这正是 [[AI Token-客户端技术知识库总纲]]、[[AI Token-桌面客户端]]、[[AI Token-编程Agent]]、[[AI Token-应用编排平台]] 系列模块的真正战略意义）；把成本管理做成客户离不开的工作流（预算规则、告警阈值、部门归集、优化策略都建在我们平台上，切换成本才真正存在）；沉淀合规资产（国内市场唯一确定随时间增值、且开源方案永远补不上的资产）；服务嵌入式 Agent 客户（理性采购正是我们的主场，应提到销售优先级最前面）。

**情景依赖的下注（需决策层明确表态）**：大额囤货批发——只在供给紧张价格上行情景下有利，鉴于市场分化短期仍有机会，但必须严格执行资金上限与周转纪律，不能作为战略重心；押注单一厂商深度绑定——能换取更好价格支持，但会在该厂商直销下沉时反噬，与"单一上游不超过 40%"的铁律冲突时以铁律为准；自建前端应用/入口——与公司能力结构相距甚远，且会与客户直接竞争，判断是不做，若决策层要做需清楚这是转型而非延伸。

## 观察指标：什么会证明谁对谁错

建议按季度检查五项，任何一项出现明确信号应触发战略复盘：**指标一**主流模型 API 单价方向——持续上行说明电力化论证暂时失效，重新单边下行且跌破成本线说明补贴战重启，批发业务应立即收缩；**指标二**厂商直销团队下沉深度——一旦开始直接争取月消费十万级以下客户，渠道代理业务进入倒计时；**指标三**头部模型在 Agent 长程任务上的能力差距——持续拉大则聚合路由价值下降、选型咨询价值上升，快速收敛则相反；**指标四**客户流失原因构成——"找到更便宜的"占主导说明能力锁定没建立起来，"业务萎缩"占主导说明位置是稳的（这是唯一能完全自主观测、最诚实的指标）；**指标五**增值服务渗透率——目标 30%，长期上不去意味着始终没跳出通道生意。

## 一句话结论

论点方向对、机制错、结论自相矛盾。方向对：价值确实在向掌握需求的一端转移，嵌入式 Agent 确实是理性采购的主场。机制错：价格不会因无尽烧钱归零，推理边际成本有硬底，2026 年市场实际是分化而非单向；真正的威胁是厂商向上游走带来的脱媒，不是价格战。结论矛盾：如果入口为王，通用型应用开发者恰恰是被夹击的一层。而对我们最重要的是它没说出口的推论——这套否定模型厂商护城河的逻辑，用在我们这一层更成立，我们没有模型能力、没有品牌、没有沉没成本，是整条链上最容易被绕过的一环。**战略只有一句话：在还能卖 token 的窗口期里，把自己变成客户离不开的东西。窗口有多长不确定，但它一定在关闭。**
