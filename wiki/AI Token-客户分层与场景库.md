# AI Token 客户分层与场景库

[[AI Token 业务]]（SpaceTiD）把客户分成四类，销售的第一课是先认清对面坐的是哪一类——他们的痛点排序、决策链长短、销售打法完全不同，用同一套话术打四类客户是最常见的失败原因。

## 四类客户画像

**AI 应用创业公司**：团队 5–50 人，产品已上线或在内测，融资阶段天使到 A 轮，技术负责人常常就是创始人。他们最怕的不是价格，而是被官方限流打出线上事故——很多创始人正是被限流一次之后才来找我们的；第二怕的是 Agent 类功能烧钱烧到失控却没人能提前算清楚；第三是频繁切换/接入新模型的工程负担。决策链极短（CTO 或创始人一人拍板），销售周期可以短到 1–2 周，但也可能同样快地被推翻。打法是直接给测试额度，让客户自己跑通结果和账单，而不是讲 PPT。风险是这类客户死亡率高，需要控制授信额度、少给账期。

**中大型企业客户**：员工数百人以上，有独立 IT/数字化部门，预算走年度流程。痛点第一位是合规与可审计——谁批的、花在哪、数据去哪、出事谁负责，2026 年起对第三方模型调用的公示与留存要求（见 [[AI Token-合规与风险控制]]）让这一点更硬；第二是内部成本要能按部门/项目拆分核算；第三是供应商资质、合同、发票、SLA 是否能过供应商准入审查；第四才是模型能力覆盖。价格通常排在第五位甚至更后，销售在这类客户面前主动降价反而是严重失误，会让对方怀疑专业性。决策链长：业务部门提需求 → IT 技术评估 → 采购比价与合规审查 → 法务审合同 → 财务定付款条件 → 领导签批，销售必须同时识别使用者、技术把关人、经济决策者、流程守门人四个角色，漏一个就会在最后一刻卡住。周期常态 4–12 周，复杂项目可达半年。打法是从一个具体部门的具体场景切入做 POC，用小项目建信任再横向扩展，不要一上来就谈全公司框架协议。

**中小企业与开发者**：几人到几十人的公司或个人开发者，月消费几百到几千元，需求零散。痛点依次是注册充值门槛、不知道选哪个模型、开票麻烦、价格。决策链就是一个人，销售周期以小时计。这类客户完全不该用人力销售去谈——获客要靠内容、SEO、开发者社区和顺畅的自助注册，人力成本算不回来。但战略价值不小：他们是口碑扩散源，也是产品的压力测试场，会最快发现产品的所有毛病。

**下游代理商与渠道伙伴**：本地 IT 服务商、软件开发商、系统集成商、行业 SaaS 公司，以及想做 AI 生意但没技术能力的创业者——他们有客户关系没产品，我们有产品没他们的客户关系（详细体系见 [[AI Token-渠道与代理商体系]]）。痛点依次是能不能低门槛开始、分润够不够结算稳不稳、能不能用自己品牌、技术售后谁兜底。给渠道伙伴的第一份材料应该是收益测算表，不是产品介绍。最大风险是渠道失控——低价窜货、虚假宣传、服务质量拖累品牌，以及最危险的代理商把通道卖给违规客户（见 [[AI Token-合规与风险控制]]）。

## 客户结构的健康标准

四类客户任何一类的收入占比都不应超过 40%（这是贯穿全局的基本认知之一，见 [[AI Token 业务]]）。补充两条硬指标：单一客户收入占比不应超过 15%，超过就意味着该客户拥有了定价权，其流失会直接冲击生存；账期客户的应收总额不应超过月收入的 1.5 倍，超过意味着在给客户垫资，现金流风险陡增。

## 高价值场景库

场景筛选标准是"token 消耗量大 + 付费意愿强 + 我们能提供额外价值"：

- **智能客服与工单处理**：消耗稳定可预测，ROI 容易算清楚，价值点在成本可预测和高峰期多模型降级。
- **代码生成与研发助手**：当下 token 消耗最猛、也最容易失控的场景（Uber 案例即出自此类），预算管控和部门归集功能在这里是刚需。
- **文档处理与知识库问答**：长上下文输入为主，输入输出比可达 50:1，缓存优化空间极大，最容易做出"帮你省了 40%"的效果，适合作为首单切入点。
- **内容生成与营销素材**：输出为主、单价高，客户对模型选型有真实需求，适合销售模型选型咨询能力。
- **多 Agent 工作流与自动化**：消耗量最大、增长最快、最不可预测（米哈游 13 小时 200 万的案例出自这里），客户几乎必然需要熔断和告警能力。
- **数据分析与报表生成**：批量任务为主、对延迟不敏感，是批量调用折扣和低价模型路由策略降低成本的最佳场景。

## 场景化开场问题库

好的销售不是讲产品，是问出客户自己都没意识到的问题——目的是暴露一个客户答不上来的空白，一旦空白被客户自己看见，销售就从"推"变成了"拉"。通用三问：现在同时用几个模型、上月 AI 支出能不能拆到具体功能、主力模型明天限流两小时的应急方案是什么。面对研发场景问预算控制；面对企业 IT 问成本归属和调用记录留存；面对创业公司 CTO 问系统提示词是否每次重传（几乎总能引出缓存优化机会）；面对渠道伙伴问他有多少客户提过 AI 需求但他答不了。这套问题库也是 [[AI Token-销售方法论与话术库]] 三段式流程第一段"暴露空白"的具体弹药。
